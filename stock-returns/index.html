Each horizon uses a different set of windows; longer windows are fewer and overlap heavily. A positive endpoint return can still include large losses along the way. In real mode, positive returns indicate purchasing-power growth.

How to read these findings

Compounding and purchasing power

For each holding period, we compound the annual returns, convert the result into an equivalent annual growth rate, and report the lowest and highest outcomes.

Nominal = [∏ (1 + rᵧ)]1 / N − 1
Real = [∏ (1 + rᵧ) × CPIstart−1, Dec / CPIend, Dec]1 / N − 1

N is the number of years. A 5-year window advances one calendar year at a time: 1928–1932, 1929–1933, and so on. There are 98 − N + 1 windows for each horizon.

Real returns use the all-items CPI-U, U.S. city average, not seasonally adjusted (1982–84 = 100). Each calendar-year window runs from the preceding December CPI to its ending December CPI. For example, 2000–2009 uses December 1999 and December 2009. December CPI is a monthly price index, not a daily year-end observation. The adjustment divides by the cumulative price change; it does not simply subtract inflation rates.

This is a buy-and-hold calculation with reinvested dividends, with no contributions or withdrawals during a window. Monthly starting dates could produce different extremes.

Source & boundaries

  • Snapshot: 1928–2025; source updated January 5, 2026; retrieved September 22, 2026.
  • Calculations use the published annual returns rounded to two decimal percentage points. Other total-return datasets can differ.
  • Real mode adjusts for CPI inflation; nominal mode does not. Both exclude taxes, investment fees, and trading costs. CPI measures an average consumption basket, not personal spending.
  • Inflation source: BLS Historical CPI-U, December 2025 (XLSX), Index Levels sheet, December column, 1927–2025. Retrieved October 17, 2026.
